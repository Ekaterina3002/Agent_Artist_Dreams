# Артефакты coding-агента

## Инструмент
Coding-агент: SourceCraft

## Начальный промпт
Создай статический сайт-галерею для проекта «Агент-художник».
Тема: «Сны нейросетей» — 5 сюрреалистичных картин.

Требования:
- index.html + style.css + script.js
- Читает data/painting_*.json
- Для каждой картины: Yandex ART V1, V2 (после VLM), Stable Diffusion
- Диалог агентов (Сновидец → Толкователь → Арт-директор)
- Критика VLM для V1 и V2
- Тёмная тема, минимализм, Manrope + DM Sans
- Адаптив под мобильные
- Модальное окно для просмотра картины

## Итерации
1. Первая генерация — базовая галерея
2. Правка: добавить сравнение V1 / V2 / SD
3. Правка: добавить график оценок VLM
4. Правка: улучшить мобильную вёрстку
