# История промптов для coding-агента

## Промпт 1 — начальный
Создай статический сайт-галерею для проекта «Агент-художник».
Тема: «Сны нейросетей» — 5 сюрреалистичных картин.
Читает data/painting_*.json. Тёмная тема, минимализм.

## Промпт 2 — сравнение версий
Добавь для каждой картины переключение между тремя версиями:
Yandex ART V1, Yandex ART V2 (после VLM), Stable Diffusion.

## Промпт 3 — график VLM
Добавь секцию «Исследование» с графиком оценок VLM до и после.
Средние баллы: 7.35 -> 7.75.

## Промпт 4 — мобильная вёрстка
Улучши адаптив: на экранах < 700px скрыть лишние пункты меню,
перестроить карточки в одну колонку, уменьшить шрифты.
