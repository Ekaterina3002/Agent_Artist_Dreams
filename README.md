# Сны нейросетей — Agent Artist

Лабораторная работа по курсу «Генеративные модели и Prompt Engineering».

**Выполнили:** Екатерина Сазонова, Мадина Жувангараева, М8О-205-СВ

## Тема коллекции

**«Сны нейросетей»** — коллекция из 5 сюрреалистичных картин, созданных
многоагентной системой. Три LLM-агента (Сновидец → Толкователь → Арт-директор)
создают концепцию сна, изображение генерируется через Yandex ART и Stable
Diffusion 1.5, а VLM-критик оценивает результат и предлагает улучшения.

## Архитектура

1. **MAS** — диалог трёх LLM-агентов → финальный промпт
2. **Генерация** — Yandex ART (Alice AI ART) + Stable Diffusion 1.5
3. **VLM-контур** — оценка → уточнение промпта → повторная генерация
4. **Сайт** — галерея на GitHub Pages

## Структура

- `Agent_Artist.ipynb` — весь код
- `data/` — JSON с диалогами агентов и VLM-отзывами
- `images/` — картины Yandex ART (V1 + V2)
- `stable_diffusion/` — картины SD 1.5
- `Agent_Artist_site/` — веб-галерея
- `vlm_scores.csv` — сводка оценок VLM
